# RecicleFácil

Projeto web colaborativo desenvolvido com foco em conscientização sobre o descarte correto de materiais recicláveis e localização de pontos de coleta.

## Sobre o projeto

O RecicleFácil foi desenvolvido em equipe com a proposta de facilitar o descarte de materiais recicláveis e incentivar práticas sustentáveis.

A proposta do projeto incluía:

- cadastro de usuários;
- cadastro de parceiros;
- localização de pontos de coleta;
- perfil do usuário;
- sistema de recompensas com moeda verde;
- utilização de QR Code;
- solicitação de coleta domiciliar.

## Minha participação

Minha contribuição no projeto envolveu atividades de desenvolvimento front-end e colaboração em equipe, incluindo:

- desenvolvimento e ajustes de interfaces com HTML e CSS;
- estilização da tela de cadastro;
- estilização da tela de login;
- ajustes na página de pontos de coleta;
- validação do nome completo no formulário de cadastro;
- implementação de campos obrigatórios com JavaScript;
- correções e ajustes de responsividade;
- trabalho colaborativo com Git e GitHub;
- uso de branches e pull requests.

## Tecnologias utilizadas

## Trabalho em equipe

O projeto foi desenvolvido de forma colaborativa, utilizando branches individuais, commits e pull requests para integração das alterações.
